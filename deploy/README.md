# Размещение сайта на VPS

Эта настройка предназначена для Linux VPS с установленным Docker Engine и
плагином Docker Compose. Caddy автоматически получит HTTPS-сертификат для
домена. Клиент сайта и API доступны посетителям через один домен; порт API
не публикуется напрямую в интернет. Отзывы сохраняются в Docker volume.

## Перед началом

1. Купите домен и VPS с Ubuntu. Для сборки Docker-образов прямо на сервере
   возьмите тариф хотя бы с 2 ГБ RAM; сборка может временно использовать
   заметную часть памяти.
2. В панели домена направьте запись `A` на публичный IPv4-адрес VPS.
   Если используете `www`, отдельно настройте его запись и домен в Caddy.
3. Установите Docker Engine и Compose по официальной инструкции Docker для
   Ubuntu. В сетевом экране VPS разрешите входящие TCP-порты `22`, `80` и
   `443`. Порт `3001` открывать не нужно.
4. Загрузите код проекта на сервер (например, через Git).

## Настройка

В корневой папке проекта:

```sh
cp .env.production.example .env
nano .env
```

Укажите домен без `https://` в `DOMAIN`, а полный HTTPS-адрес — в
`SITE_ORIGIN`. Например:

```dotenv
DOMAIN=example.ru
SITE_ORIGIN=https://example.ru
```

Задайте SMTP-данные в `server/.env`. Можно скопировать
`server/.env.example`, затем заменить примерные значения на настоящие.
Для Gmail нужен пароль приложения, а не обычный пароль от аккаунта.
Не отправляйте пароли в чат и не добавляйте `.env` в Git.

Проверьте, что DNS уже указывает на VPS и домен открывается снаружи:

```sh
docker compose config
docker compose up -d --build
docker compose ps
```

API станет healthy только после настройки SMTP. После запуска откройте
`https://ваш-домен`; проверьте форму заказа и отзывы. Для теста отправки
сделайте заявку и убедитесь, что письмо пришло на почту получателя.

## Обновление и резервная копия отзывов

После обновления кода:

```sh
git pull
docker compose up -d --build
```

Сохраните отзывы в резервную копию перед переносом или обслуживанием:

```sh
docker compose exec -T api cat /app/data/reviews.json > reviews-backup.json
```

Храните резервную копию отдельно от VPS. Удаление Docker volume
`reviews_data` удалит отзывы. Текущая JSON-база рассчитана на один экземпляр
API.

## SEO после публикации

При сборке Docker передаёт `SITE_ORIGIN` в клиент. Поэтому в сборке появятся
адреса страниц, canonical-ссылки, `robots.txt` и `sitemap.xml`. После запуска
добавьте сайт в Яндекс Вебмастер и Google Search Console и отправьте им
`https://ваш-домен/sitemap.xml`.

Перед этим проверьте правильность контактов, описания услуг, города или
региона работы и политики конфиденциальности. Указывайте только реальные
цены, сроки и условия.
